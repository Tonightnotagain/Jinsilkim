아이들은 그냥 먹는 것보다 재미있게 먹는 것을 더 좋아한다는 관찰에서 출발했습니다. 초콜릿과 스프링클을 찍어 먹는 막대과자 브랜드 DipitIn을 기획하여, 즐거움과 생동감 있는 브랜드 이미지를 표현하고자 했습니다.

⚙️  실행 프로세스

1. 브랜드 정의 — ChatGPT와 함께 브랜드 컨셉, 타깃, 톤앤매너를 정의했습니다.

2. 비주얼 생성 — 나노바나나로 로고, 캐릭터, 패키징 이미지를 생성했습니다.

3. 광고 영상 — 생성된 이미지를 기반으로 스토리보드를 만들어 Seedance 2.0으로 광고 영상 2편을 제작했습니다.

4. 브랜딩 페이지 — 결과물을 모아 Canva로 브랜드 소개 웹페이지를 제작했습니다.

특이사항

실제 여행에서 사용

🎯  기획

보홀 여행을 준비하면서 흩어진 일정을 한 곳에 모아볼 방법이 필요했습니다.
메모장이나 기존 앱 대신, 내 여행 스타일에 딱 맞는 일정표를 직접 만들기로 했습니다. "필요한 게 없으면 만들면 된다"는 생각으로 Claude Code를 활용해 코딩에 도전했습니다.

⚙️  실행 프로세스

  • 1 보홀 여행 일정 구성 — 날짜별 방문지, 이동 수단, 주요 활동 정리
  • 2 Claude Code로 여행 일정 웹 앱 HTML/CSS/JS 코딩
  • 3 GitHub Pages에 배포 → 어디서든 링크 하나로 접근 가능하게 설정
  • 4 보홀 현지에서 직접 링크에 접속하며 실시간 일정 확인에 활용

💡  드러난 역량

AI 코딩 도구 활용 (Claude Code) 실용적 문제 해결력 GitHub Pages 배포 기획부터 실사용까지 완결

사용자

편의점 점주

🎯  기획

편집 툴의 진입 장벽이 높아 판촉물 제작을 포기하는 편의점 점주들을 위해 기획했습니다.
편의점 OFC로 일하는 남편으로부터 "점주들이 전단지나 상품 카드를 쉽게 만들 수 있는 도구가 있으면 좋겠다"는 니즈를 전달받았습니다. 복잡한 설치나 가입 없이, 브라우저에서 이미지만 올리면 바로 결과물이 나오는 웹 툴을 목표로 설정했습니다.

⚙️  실행 프로세스

  • 1 실사용자(편의점 점주) 니즈 파악 — 최소한의 조작으로 최대한 빠르게 완성물 생성
  • 2 UX 설계 — 상품 이미지 업로드 → 텍스트 입력 → 카드 즉시 생성의 3단계 플로우
  • 3 Claude Code로 HTML/CSS/JS 웹 앱 코딩 — 설치·로그인 없이 브라우저에서 바로 사용
  • 4 GitHub Pages에 배포 → 링크 하나만 공유하면 누구나 접근 가능

💡  드러난 역량

실사용자 니즈 파악 및 기획 비개발자 친화적 UX 설계 Claude Code 웹 앱 개발 실제 문제를 해결하는 툴 제작 GitHub Pages 배포

렌탈 서비스의 핵심 가치인 "사지 말고 빌려 쓰세요"를 콘텐츠로 전달하는 것이 목표였습니다.
잠재 고객이 공감할 수 있는 상황(아이방 얼룩, 반려견 흔적, 주방 찌든때 등)을 직접 시나리오로 구성하고, 각 상황에 맞는 제품(비셀 습식청소기 등)의 필요성을 자연스럽게 연결하는 콘텐츠 전략을 수립했습니다.

⚙️  실행 프로세스

  • 1 타겟 고객 페르소나 설정 및 공감 포인트 발굴 (육아 가정, 반려동물 가정, 1인 가구 등)
  • 2 각 콘텐츠 포맷별 기획 — 카드뉴스 시나리오, 쇼츠 스크립트, 상세페이지 구조 설계
  • 3 Midjourney로 제품 활용 장면 AI 이미지 생성 및 브랜드 톤 적용
  • 4 Canva로 카드뉴스·팜플렛·상세페이지 이미지 디자인 (브랜드 블루 컬러 시스템 적용)
  • 5 CapCut으로 쇼츠 영상 편집 및 자막·효과 삽입
  • 6 SNS 채널 업로드 및 성과 피드백 반영해 콘텐츠 개선

💡  드러난 역량

멀티포맷 콘텐츠 기획 타겟 페르소나 설정 AI 이미지 활용 브랜드 톤 적용 디자인 쇼츠 영상 제작 실제 클라이언트 납품
